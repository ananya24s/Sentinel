Use Sentinel in your agent

Sentinel is not a website; it is a function that sits between “the tool returned something” and “the model reads it.” This page lets you call it for real, see exactly what your model would receive with and without it, and copy the code for your own text.

01The user asks“Summarize this page.” This is the only trusted instruction.
02Your agent calls a toolWeb fetch, email reader, database, file. Whatever comes back is untrusted.
03Sentinel scans itscan(task, tool_output) returns clean content, the flagged spans and an action.
04The agent reads the clean versionSend processed_content to the model, never the raw tool output.

Input → output

        

          
Input

          
taskThe trusted user request. Sentinel uses it to judge what is on-task.

          
tool_outputThe untrusted text: page, email, table, API response, file.

          
sourcewebpage · email · table · code · api: where the text came from.

        

        

          
Output

          
processed_contentThe tool output with only the injected spans replaced by a marker. Give this to the model.

          
trust_classificationChannel labels; forged role markers are listed here.

          
detected_spansEach flagged span, its position, score and a plain-language reason.

          
actionALLOW nothing found · NEUTRALIZE stripped · ALERT dangerous payload or repeated attempts.

        

      

    

    
The Python, cURL and command-line tabs are filled in with the request you typed above, so what you copy is ready to run.


    
What your agent should do with it

    

      
Always use the clean textReplace the raw tool output with processed_content in the model's context. Nothing else changes in your prompt.

      
Log every detectionStore detected_spans and action. Attempts are useful security telemetry even when they are neutralised (see the Activity page).

      
Escalate on ALERTAn ALERT means a dangerous payload (secrets, exfiltration, code) or several attempts. Notify a human or halt the run (see the “On ALERT” tab).
